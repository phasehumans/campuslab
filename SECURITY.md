# Security Policy

Security is a top priority for December. Responsible disclosure of security vulnerabilities helps keep the project safe for everyone.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

### Where to Report

- **Private Security Advisory**: [Create a Security Advisory](https://github.com/phasehumans/campuslab/security/advisories/new)
- **Email**: [team@trydecember.com](mailto:team@trydecember.com)

### What to Include

To help us investigate and resolve the issue as quickly as possible, please include:

- Description of the vulnerability and its impact
- Clear steps or code to reproduce the issue
- Affected components or packages

### Response Timeline

- Reports will be acknowledged within 48 hours.
- Regular updates will be provided until a fix is released.
