Campus Lab is a free, open-source coding platform for college programming labs. Teachers can run live coding contests during lab time. Students can practice problems, compete with friends, and see right away if their code works. It runs on your college's own server.

- **250+ Problems:** Practice problems, each checked with 30 hidden tests. Your time and past submissions are saved.
- **Live Contests:** Contest rooms with a live leaderboard. Fullscreen lock and paste blocking help stop cheating.
- **1v1 Duels:** Challenge a friend and see who solves the problem first.
- **Problem of the Day:** A new problem every day to keep your streak going.
- **Playground:** Write and run code in your browser. No account needed.
- **Safe Code Runner:** Every submission runs in a locked sandbox, so student code can't harm the server.

### Research

Campus Lab began as a semester project at SES's R. C. Patel Institute of Technology (RCPIT), Shirpur. We tested it for 16 weeks with 64 second-year AI&ML students and published the results in **[Real-Time Coding Contests in College Programming Labs: A Case Study at RCPIT Shirpur](https://ijarcce.com/papers/real-time-coding-contests-in-college-programming-labs-a-case-study-at-rcpit-shirpur/)** (IJARCCE).

- With contests, students finished **88.5%** of their lab problems in class. With homework, they finished only **61.2%**.
- Students scored **5.8 marks more** (out of 50) in practical exams on topics they learned through contests.
- Students needed fewer tries per problem, down from **5.7 to 3.2**, because they tested and planned before submitting.
