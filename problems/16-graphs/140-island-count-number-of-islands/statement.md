Given an R x C 2D binary grid map of 1s (land) and 0s (water), return the number of islands.

An island is a maximal group of land cells connected horizontally or vertically (diagonal neighbours do not count). The area outside the grid is water.

**Input Format:**
- First line: R C
- Next R lines: C values (0 or 1)

**Output Format:**
- A single integer representing the count of islands.
