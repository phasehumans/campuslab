Given a weighted, undirected graph with N vertices (labeled 0 to N-1) and M edges, and a source vertex S. Find the shortest distance from the source vertex S to all vertices in the graph (the distance from S to itself is 0). If a vertex is unreachable, the distance should be -1.

**Input Format:**
- First line: N M S
- Next M lines: u v w (undirected edge between u and v with weight w)

**Output Format:**
- A single line of space-separated integers representing the shortest distance from source S to vertices 0 to N-1.
