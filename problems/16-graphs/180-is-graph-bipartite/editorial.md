We can color the vertices using two colors (say 0 and 1). Start traversal (BFS/DFS) on each unvisited component. For the starting node, color it 0. For any visited node, color its unvisited neighbors with the opposite color. If we encounter an adjacent node already colored with the same color as the current node, the graph is not bipartite. If the entire graph is colored without conflict, it is bipartite.
