Given an undirected graph with N vertices (labeled 0 to N-1) and M edges, determine if the graph is bipartite.

A graph is bipartite if we can partition the vertices into two independent sets A and B such that every edge in the graph connects a vertex in A and a vertex in B. Note that the graph may have multiple disconnected components.

**Input Format:**
- First line: N M
- Next M lines: u v (undirected edge between u and v)

**Output Format:**
- 'true' if the graph is bipartite, otherwise 'false'.
