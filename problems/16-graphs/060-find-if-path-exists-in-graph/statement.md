Given an undirected graph with N vertices (labeled 0 to N-1) and M edges, determine if there is a valid path from a source vertex to a destination vertex. A vertex always has a path to itself.

**Input Format:**
- First line: N M
- Next M lines: u v (undirected edge between u and v)
- Last line: source destination

**Output Format:**
- 'true' if path exists, otherwise 'false'.
