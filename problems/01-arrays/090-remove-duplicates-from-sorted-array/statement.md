Given a sorted array of integers, remove the duplicates in-place such that each element appears only once and return the new length m.

Print the new length m, followed by the first m elements of the modified array.

**Input Format:**
- First line: integer n
- Second line: n space-separated sorted integers

**Output Format:**
- First line: a single integer representing the new length m
- Second line: m space-separated integers representing the unique elements in the modified array
