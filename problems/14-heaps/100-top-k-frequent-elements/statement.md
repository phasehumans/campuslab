Given an integer array nums and an integer k, return the k most frequent elements.

To ensure a unique result:
- Sort the elements in descending order of frequency.
- If two elements have the same frequency, the one with the larger numerical value must come first.

**Input Format:**
- First line: two integers n (size of array) and k
- Second line: n space-separated integers

**Output Format:**
- A single line containing k space-separated integers, representing the top k frequent elements sorted as specified.
