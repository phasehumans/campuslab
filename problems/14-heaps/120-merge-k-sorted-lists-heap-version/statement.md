You are given k sorted arrays. Merge them into a single sorted array.

Your solution must use a Min-Heap / Priority Queue strategy to merge the arrays.

**Input Format:**
- First line: integer k (number of arrays)
- Each of the next k lines represents an array: first value is an integer m_i (the size of that array), followed by m_i space-separated sorted integers.

**Output Format:**
- A single line containing all sorted elements space-separated. If the merged output is empty, output an empty line.
