Given a list of unique words, find all pairs of distinct indices (i, j) in the given list, so that the concatenation of the two words, i.e., words[i] + words[j] is a palindrome.

**Input Format:**
- First line: integer n, the number of words.
- Next n lines: each contains a word.

**Output Format:**
- First line: integer p, the number of palindrome pairs found.
- Next p lines: two space-separated integers i and j representing the indices of the matching pair. The pairs should be sorted first by i, and then by j.
