Given an m x n board of characters and a list of strings words, return all words on the board.

Each word must be constructed from letters of sequentially adjacent cells, where adjacent cells are horizontally or vertically neighboring. The same letter cell may not be used more than once in a word.

**Input Format:**
- First line: two integers m and n (board dimensions).
- Next m lines: a string of length n representing the row of the board.
- Next line: an integer w, the number of words.
- Next w lines: each containing a word to search.

**Output Format:**
- The words found on the board, sorted in lexicographical order, one per line.
