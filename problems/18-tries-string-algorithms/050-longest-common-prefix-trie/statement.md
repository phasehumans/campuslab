Given a list of n strings, and an integer k, find the longest prefix that is shared by at least k strings.

If there are multiple prefixes of the maximum length, return the lexicographically smallest one. If no prefix of length >= 1 is shared by at least k strings, output an empty line.

**Input Format:**
- First line: two integers n and k.
- Next n lines: each contains a string s_i consisting of lowercase English letters.

**Output Format:**
- The lexicographically smallest prefix of maximum length shared by at least k strings. If none, print an empty line.
