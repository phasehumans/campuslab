Given a string `s`, consider all duplicated substrings: substrings of `s` that occur 2 or more times. The occurrences may overlap.

Find a duplicated substring of the longest possible length. If several different substrings have that maximum length, print the one whose **first occurrence starts earliest** in `s`. If `s` does not have a duplicated substring, print an empty line.

**Input Format:**
- A single line containing the string `s` consisting of lowercase English letters.

**Output Format:**
- A single string representing the longest duplicate substring (or an empty line if none).
