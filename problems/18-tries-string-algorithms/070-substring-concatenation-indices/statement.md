You are given a string `s` and an array of strings `words`. All strings in `words` are of the exact same length.

A concatenated substring in `s` is a substring that contains all the strings of any permutation of `words` concatenated.

Find all starting indices of concatenated substrings in `s`.

Print the starting indices in ascending order, separated by spaces. If no such indices exist, print an empty line.

**Input Format:**
- First line: string `s`
- Second line: integer `m` (number of words in the array)
- Next `m` lines: each line contains a word from the array `words`.

**Output Format:**
- A single line of space-separated indices in ascending order.
