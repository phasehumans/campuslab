Write an efficient algorithm that searches for a target value in an M x N integer matrix. This matrix has the following properties:
- Integers in each row are sorted in ascending from left to right.
- Integers in each column are sorted in ascending from top to bottom.

Output `true` if the target is found in the matrix, and `false` otherwise.

**Input Format:**
- First line: three space-separated integers M, N, and target, representing the number of rows, the number of columns, and the target value.
- Next M lines: each contains N space-separated integers representing the matrix.

**Output Format:**
- Print `true` if the target exists in the matrix, otherwise print `false`.
