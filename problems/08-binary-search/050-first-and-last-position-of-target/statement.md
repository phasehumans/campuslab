Given an array of integers sorted in non-decreasing order, find the starting and ending position of a given target value.

If the target is not found in the array, return [-1, -1] as two space-separated integers.

You must write an algorithm with O(log N) runtime complexity.

**Input Format:**
- First line: two space-separated integers N and target
- Second line: N space-separated integers representing the sorted array

**Output Format:**
- Two space-separated integers: the start index and end index of the target
