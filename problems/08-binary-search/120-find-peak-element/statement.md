A peak element is an element that is strictly greater than its neighbors. Given a 0-indexed integer array, find a peak element, and return its index.

You may imagine that arr[-1] = arr[N] = -infinity. In other words, an element is always considered to be strictly greater than a neighbor that is outside the array.

You must write an algorithm with O(log N) runtime complexity. All test cases will have a unique peak index (i.e., the array is unimodal).

**Input Format:**
- First line: integer N
- Second line: N space-separated integers

**Output Format:**
- A single integer: the index of the peak element
