Given two sorted arrays nums1 and nums2 of size m and n respectively, return the median of the two sorted arrays.

The overall run time complexity should be O(log (m+n)).

To ensure exact output match without float formatting issues, return the result as a string representation of a double value, rounded to 5 decimal places.

**Input Format:**
- First line: two integers m and n (sizes of the two arrays)
- Second line: m space-separated integers representing nums1
- Third line: n space-separated integers representing nums2

**Output Format:**
- A single decimal number representing the median, printed with exactly 5 decimal places
