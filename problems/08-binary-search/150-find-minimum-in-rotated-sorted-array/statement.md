Suppose an array of length N sorted in ascending order is rotated between 1 and N times.

Given the sorted rotated array of unique elements, return the minimum element of this array.

You must write an algorithm that runs in O(log N) time.

**Input Format:**
- First line: integer N
- Second line: N space-separated integers representing the rotated sorted array

**Output Format:**
- A single integer: the minimum element in the array
