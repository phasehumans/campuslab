The distance of a value pair (A, B) is defined as the absolute difference between A and B, i.e., |A - B|.

Given an integer array nums of size N and an integer K, return the K-th smallest distance among all the pairs nums[i] and nums[j] where 0 <= i < j < N.

**Input Format:**
- First line: two space-separated integers N and K.
- Second line: N space-separated integers representing the array nums.

**Output Format:**
- A single integer representing the K-th smallest distance.
