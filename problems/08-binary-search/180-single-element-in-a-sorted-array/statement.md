You are given a sorted array consisting of only integers where every element appears exactly twice, except for one element which appears exactly once.

Find this single element that appears only once.

Your solution must run in O(log N) time complexity and O(1) space complexity.

**Input Format:**
- First line: integer N (always odd)
- Second line: N space-separated integers representing the sorted array

**Output Format:**
- A single integer representing the unique element
