Given the head of a linked list, determine if it has a cycle. A cycle exists if some node can be reached again by continuously following the `next` pointer.

**Input Format:**
- First line: two integers `n` (number of nodes) and `pos` (0-indexed position where the tail connects. If `pos` is `-1`, there is no cycle).
- Second line: `n` space-separated integers representing node values.

**Output Format:**
- `1` if a cycle exists, `0` otherwise.
