You are given an array of `k` linked-lists, each linked-list is sorted in ascending order. Merge all the linked-lists into one sorted linked-list and return it.

**Input Format:**
- First line: integer `k` (number of sorted lists)
- Next `k` lines: each line contains an integer `m` (number of elements in the list) followed by `m` space-separated integers.

**Output Format:**
- Space-separated integers representing the merged sorted list
