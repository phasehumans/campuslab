Merge two sorted linked lists and return it as a new sorted list. The new list should be made by splicing together the nodes of the first two lists.

**Input Format:**
- First line: two integers `n1` and `n2` (sizes of the two lists)
- Second line: `n1` space-separated integers representing the first sorted list (empty if `n1` is 0)
- Third line: `n2` space-separated integers representing the second sorted list (empty if `n2` is 0)

**Output Format:**
- Space-separated integers representing the merged sorted list
