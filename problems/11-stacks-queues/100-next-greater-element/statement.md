Given an array of integers, find the next greater element for each element in the array. The next greater element of an element arr[i] is the first greater element to its right. If it does not exist, the next greater element is -1.

**Input Format:**
- First line: integer n (size of the array)
- Second line: n space-separated integers

**Output Format:**
- n space-separated integers, representing the next greater element for each element in the input array.
