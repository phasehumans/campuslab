An encoded string is given, decode it to its original form.

The encoding rule is: k[encoded_string], where the encoded_string inside the square brackets is being repeated exactly k times. Note that k is guaranteed to be a positive integer.

You may assume that the input string is always valid; there are no extra spaces, brackets are well-formed, etc. Furthermore, the decoded string does not contain any digits.

**Input Format:**
- A single line containing the encoded string s.

**Output Format:**
- The decoded string.
