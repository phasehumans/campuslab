Given a 2D binary matrix of dimensions r x c filled with '0's and '1's, find the largest rectangle containing only '1's and return its area.

**Input Format:**
- First line: two integers r and c (rows and columns)
- Next r lines: each line containing a string of length c consisting of '0' and '1' characters (no spaces)

**Output Format:**
- A single integer representing the area of the largest rectangle.
