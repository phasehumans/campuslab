Evaluate a string s representing a valid arithmetic expression.

The expression contains parentheses '(', ')', plus '+', minus '-', non-negative integers and empty spaces. A minus sign may also be unary (like -2 or -(3+4)), but only at the very start of the expression or directly after an opening parenthesis; '+' is never unary. Spaces can occur anywhere except inside a number.

**Input Format:**
- A single line containing the expression string s.

**Output Format:**
- A single integer representing the evaluated value.
