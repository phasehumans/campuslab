Given a chessboard of size R x C and a starting position (r, c) of a knight, determine if there is a sequence of moves for the knight such that it visits every cell on the board exactly once. The knight moves in a standard L-shape (2 squares in one direction and 1 square in a perpendicular direction).

**Input Format:**
- First line: two space-separated integers R and C
- Second line: two space-separated integers r and c representing the starting coordinates (0-indexed)

**Output Format:**
- The string "true" if a complete knight's tour is possible, otherwise "false"
