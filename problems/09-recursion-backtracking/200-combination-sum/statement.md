Given an array of distinct integers candidates and a target integer, return the number of unique combinations where the chosen numbers sum to the target. You can choose any candidate integer an unlimited number of times. Two combinations are the same if they use every candidate the same number of times (order does not matter). It is guaranteed that the answer fits in a 32-bit signed integer.

**Input Format:**
- First line: two space-separated integers n and target
- Second line: n space-separated candidate integers

**Output Format:**
- A single integer representing the number of unique combinations that sum to target
