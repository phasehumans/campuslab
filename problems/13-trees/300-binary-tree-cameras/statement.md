You are given the root of a binary tree. We install cameras on the tree nodes where each camera at a node can monitor its parent, itself, and its immediate children. Calculate the minimum number of cameras needed to monitor all nodes of the tree.

**Input Format:**
- A single line containing the BFS level-order serialization of the tree (using 'null' for empty nodes).

**Output Format:**
- An integer representing the minimum number of cameras.
