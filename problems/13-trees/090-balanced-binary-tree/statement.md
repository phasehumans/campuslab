Given the root of a binary tree, determine if it is height-balanced.

A height-balanced binary tree is defined as a binary tree in which the left and right subtrees of every node differ in height by at most 1.

**Input Format:**
- A single line containing the BFS level-order serialization of the tree (using 'null' for empty nodes).

**Output Format:**
- 'true' or 'false' (lowercase string).
