Given an `N x M` matrix, find the maximum path sum from any cell of the first row to any cell of the last row. At each cell `(i, j)`, you can move to `(i+1, j)`, `(i+1, j-1)`, or `(i+1, j+1)`.

**Input Format:**
- First line: two space-separated integers N and M
- Next N lines: M space-separated integers representing the matrix rows

**Output Format:**
- A single integer: the maximum path sum.
