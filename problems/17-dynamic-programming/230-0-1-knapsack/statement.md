Given weights and values of `n` items, and a knapsack of capacity `W`, find the maximum value that can be put in the knapsack. You cannot split items; you either take them (1) or leave them (0).

**Input Format:**
- First line: two integers n and W (number of items and capacity of the knapsack)
- Second line: n space-separated integers representing the values of each item
- Third line: n space-separated integers representing the weights of each item

**Output Format:**
- A single integer: the maximum value that can be stashed.
