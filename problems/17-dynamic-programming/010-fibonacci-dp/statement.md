Calculate the n-th Fibonacci number.

The Fibonacci numbers are defined as:
- F(0) = 0
- F(1) = 1
- F(n) = F(n-1) + F(n-2) for n >= 2

Since the result can be very large, print F(n) modulo 1,000,000,007 (10^9 + 7).

**Input Format:**
- A single line containing an integer n.

**Output Format:**
- A single integer: F(n) % 1000000007.
