You are given an integer array cost where cost[i] is the cost of the i-th step on a staircase. Once you pay the cost, you can either climb one or two steps.

You can start from the step with index 0, or the step with index 1.

Return the minimum cost to reach the top of the floor (one step beyond the last element of the array).

**Input Format:**
- First line: an integer n (the number of steps)
- Second line: n space-separated integers representing the cost of each step

**Output Format:**
- A single integer: the minimum cost to reach the top.
