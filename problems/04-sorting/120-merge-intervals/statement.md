Given a collection of intervals, merge all overlapping intervals and output the sorted list of merged intervals.

**Input Format:**
- First line: integer N, the number of intervals
- Next N lines: each contains two space-separated integers representing the start and end of an interval

**Output Format:**
- First line: integer M, the number of merged intervals
- Next M lines: each contains two space-separated integers representing the merged intervals sorted by their start times
