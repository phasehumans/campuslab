**Approach: Counting Sort Frequency Array**

Create a frequency array of size 101 initialized to 0. Traverse the input array and increment the frequency for each number. Finally, iterate from 0 to 100, and for any index with a non-zero count, print the index (the number) and its frequency.

**Time Complexity:** O(N)
**Space Complexity:** O(1) (since the size of the frequency array is fixed at 101)
