Given an array of N integers where all integers are between 0 and 100 (inclusive), count the frequency of each integer and output them in ascending order of the integer. Only print the integers that appear at least once, along with their frequencies.

**Input Format:**
- First line: integer N
- Second line: N space-separated integers

**Output Format:**
- For each unique integer present in the array (in ascending order), print the integer and its frequency separated by a space, each on a new line.
