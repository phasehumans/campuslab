Given four integer arrays `A`, `B`, `C`, and `D` of size `n`, return the number of tuples `(i, j, k, l)` such that:
`A[i] + B[j] + C[k] + D[l] == 0`

**Input Format:**
- First line: integer `n` (the size of each array)
- Second line: `n` space-separated integers representing array `A`
- Third line: `n` space-separated integers representing array `B`
- Fourth line: `n` space-separated integers representing array `C`
- Fifth line: `n` space-separated integers representing array `D`

**Output Format:**
- A single integer representing the count of tuples summing to 0.
