Given an unsorted array of integers `arr`, find the length of the longest run of consecutive integer values that all appear in the array. The values may appear in any order and duplicates count only once.

For example, in `[100, 4, 200, 1, 3, 2]` the values `1, 2, 3, 4` form a run of length 4.

Try to do it in O(n) expected time, without sorting.

**Input Format:**
- First line: integer `n` (the size of the array).
- Second line: `n` space-separated integers (empty when `n = 0`).

**Output Format:**
- A single integer: the length of the longest consecutive run (0 for an empty array).
