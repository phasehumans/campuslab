Given an array of integers `arr` and an integer `target`, find the two positions whose values add up to `target` and print their 1-based indices.

Each input has exactly one valid pair of positions, and you may not use the same position twice. Print the two indices in ascending order.

**Input Format:**
- First line: two space-separated integers `n` (the size of the array) and `target`.
- Second line: `n` space-separated integers.

**Output Format:**
- Two space-separated integers: the 1-based indices `i < j` such that `arr[i] + arr[j] = target`.
