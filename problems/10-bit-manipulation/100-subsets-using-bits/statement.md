Given an array of n distinct integers, generate all possible subsets (the power set) using bit manipulation. Print each subset on a separate line with elements space-separated. Print subsets in the order of their bitmask (0, 1, 2, ..., 2^n - 1). For the empty subset, print an empty line.

**Input Format:**
- First line: integer n
- Second line: n space-separated integers

**Output Format:**
- 2^n lines, each containing the elements of one subset. The i-th line corresponds to bitmask i (0-indexed).
