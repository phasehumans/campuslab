Given three integers a, b, and c, find the minimum number of bit flips in a and b such that (a OR b) equals c.

A bit flip changes a 0 to 1 or a 1 to 0 in the binary representation.

**Input Format:**
- A single line containing three space-separated non-negative integers a, b, c

**Output Format:**
- The minimum number of bit flips needed
