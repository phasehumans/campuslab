Given a binary string s representing a non-negative integer, return the number of steps required to reduce it to zero.

At each step, you must perform exactly one of the following operations:
1. If the current number is even, divide it by 2.
2. If the current number is odd, subtract 1 from it.

The input string may contain leading zeros, which should be ignored. If the value is 0, the answer is 0.

**Input Format:**
- A single line containing the binary string s.

**Output Format:**
- A single integer: the number of steps needed to reduce the number to zero.
