Given an array of integers where every element appears exactly twice except for two elements which appear only once, find the two elements that appear only once.

Print the two elements in ascending order, space-separated.

You must implement a solution with O(n) time complexity and O(1) space complexity.

**Input Format:**
- First line: integer n, the size of the array.
- Second line: n space-separated integers.

**Output Format:**
- Two space-separated integers in ascending order.
