Given an array arr of positive integers and a set of queries. Each query is represented by a pair `[left, right]`. For each query, calculate the bitwise XOR of elements from index `left` to `right` inclusive.

**Input Format:**
- First line: two space-separated integers n and q, the size of the array and the number of queries.
- Second line: n space-separated integers representing the array.
- Next q lines: two space-separated integers left and right (0-indexed).

**Output Format:**
- q lines, each containing the answer to the respective query.
