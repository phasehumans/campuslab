Given two integers a and m, find the modular multiplicative inverse of a modulo m.

Specifically, find an integer x in the range [0, m - 1] such that:
- (a * x) % m == 1

If no such integer exists, print -1.

**Input Format:**
- A single line containing two space-separated integers a and m.

**Output Format:**
- A single line containing the modular inverse of a modulo m, or -1 if it does not exist.
