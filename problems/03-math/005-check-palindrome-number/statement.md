Given an integer `x`, decide whether it is a **palindrome**, i.e. whether it reads the same from left to right and from right to left.

For example, `121` is a palindrome. `-121` is not, because read backwards it becomes `121-`. Likewise `10` is not a palindrome, because read backwards it is `01`.

**Input Format:**
- A single line containing the integer `x`.

**Output Format:**
- Print `true` if `x` is a palindrome, otherwise print `false`.
