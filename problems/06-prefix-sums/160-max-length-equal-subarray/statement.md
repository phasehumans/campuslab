Given a binary array `nums` (containing only 0 and 1), find the maximum length of a contiguous subarray with an equal number of 0 and 1.

**Input Format:**
- First line: integer `n` (the size of the array)
- Second line: `n` space-separated integers (either 0 or 1)

**Output Format:**
- Print the maximum length of such a contiguous subarray.
