Given an integer array `arr` and an integer `k`, count the **good** subarrays of `arr`.

A subarray is a contiguous, non-empty part of the array. It is good if it contains exactly `k` different values. For example, `[1, 2, 3, 1, 2]` contains 3 different values: 1, 2 and 3.

**Input Format:**
- First line: two space-separated integers `n` and `k`.
- Second line: `n` space-separated integers.

**Output Format:**
- A single integer: the number of good subarrays.
