Given an integer array `arr` and an integer `k`, return the length of the shortest non-empty subarray of `arr` with a sum of at least `k`. If there is no such subarray, return `-1`.

Note that the array can contain negative numbers.

**Input Format:**
- First line: two space-separated integers `n` and `k`.
- Second line: `n` space-separated integers.

**Output Format:**
- A single integer representing the minimum length of a subarray with sum >= k, or -1 if none exists.
