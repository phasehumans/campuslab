Given an array `arr` and an integer `val`, remove all occurrences of `val` in-place and return the new length `k`.

To make the output deterministic, print:
1. The new length `k` on the first line.
2. The first `k` elements of the modified array in sorted order, space-separated, on the second line.

You must do this in-place with O(1) extra space.

**Input Format:**
- First line: two integers `n` (the size of the array) and `val`, space-separated.
- Second line: `n` space-separated integers.

**Output Format:**
- First line: the new length `k`.
- Second line: the first `k` elements of the modified array sorted in ascending order, space-separated.
