Given a binary array `arr` and an integer `k`, return the maximum number of consecutive `1`'s in the array if you can flip at most `k` `0`s.

**Input Format:**
- First line: two space-separated integers `n` (size of the array) and `k` (max flips).
- Second line: `n` space-separated integers (either 0 or 1).

**Output Format:**
- A single integer representing the maximum consecutive 1s.
