Given two strings `s` and `t`, find the shortest substring (contiguous part) of `s` that contains every character of `t`, counting duplicates. For example, if `t = "AAB"`, the window must contain at least two `A`s and one `B`.

It is guaranteed that at least one such window exists. If several shortest windows exist, print the one that starts leftmost.

**Input Format:**
- First line: string `s`
- Second line: string `t`

**Output Format:**
- The minimum window substring.
