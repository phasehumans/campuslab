You are given an array of integers `arr` of length `n` and a window size `k`. A window of `k` consecutive elements starts at the left end of the array and slides one position to the right at a time until it reaches the right end, so there are `n - k + 1` windows.

For every window, report the maximum element inside it.

**Input Format:**
- First line: two space-separated integers `n` and `k`.
- Second line: `n` space-separated integers.

**Output Format:**
- A single line with `n - k + 1` space-separated integers: the maximum of each window, from left to right.
